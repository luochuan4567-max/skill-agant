# 小说剧情解说

先读 [制作默认值](../../references/production-defaults.md)，用户当前要求覆盖默认值。

## 输入与模式

读取用户提供的原文、剧情素材或现有稿件。收到文件或链接时先读取内容；无法读取时说明缺失，不凭标题编造剧情。长篇小说只读取本次章节和必要上下文。

- 新稿：确定本集唯一主线、核心危机和最终高潮，再组织口播。
- 改稿：保留已成立的句子，只修复实际问题，不为展示修改而全篇重写。

沿用用户指定的目标字数、视角、主线、高潮和必须保留的对白。没有明确时长或字数时依据素材组织，不擅自删掉关键转折；关键剧情缺失时先询问。

## 写作规则

1. 围绕一条主线组织“危机出现 → 人物应对 → 局势变化 → 危险升级 → 高潮与结果”。支线只有影响主线时才保留。
2. 默认前 80 字交代核心人物、危机和信息缺口。开场可以前置素材中已发生的结果，但主体叙述保持事件因果和先后关系清楚。
3. 默认每 80–120 字出现有效推进，如新危险、原因揭露、突破口、代价或局势变化。短稿按实际长度调整，不为凑节奏虚构反转。
4. 设定第一次出现时，用最少文字说明它是什么、为何重要、如何影响当前人物，不连续两段堆砌实力和世界观。
5. 明确主语、指代、行动动机和场景转换。用适合配音的现代中文短句，保留素材应有的史诗感和压迫感，避免空洞情绪词和形容词堆砌。
6. 人物行为符合身份、立场、实力及当时掌握的信息。不要把正常追杀、败退或判断改成无依据的阴谋、放水或提前布局。无法确认的心理改写为可观察行为；关键事实有歧义时标明或询问，不当作定论。

## 固定五问验收

内部检查并修复：

- 听得懂吗：不看画面，人物、事件和结果是否清楚？
- 看得明白吗：不熟悉原著的人，是否理解动机和设定作用？
- 有推进吗：每 80–120 字是否有有效变化，是否存在重复段落？
- 有主线吗：能否一句话概括本集，支线是否服务主线？
- 有高潮吗：最重要事件是否得到相应篇幅和位置，前文是否提前透支情绪？

同时核对原文，确保重要对白、因果和结果没有被改写错误。

## 输出

默认只输出可直接配音的完整成稿，不展示内部分析和修改说明。用户要求审稿或对照时，再提供具体问题与修改依据。用户指定时长时按默认语速校准篇幅，字幕按自然语义切屏。字数、时长估算只有用户需要时附上；配音时长必须注明所用语速，实际时长以录音为准。
