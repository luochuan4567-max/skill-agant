# 影视化分镜

## 输入

读取原文或口播稿、已有角色与场景母版，以及用户指定的画幅、风格、总时长和单镜限制。缺少剧情内容时先获取，不凭题目扩写。未指定时采用真实 3D CG / PBR、电影摄影感；画幅沿用项目或参考素材，无法确定时标明暂定值。

先列出本章人物、场景、能力、道具和简洁关系箭头图。给角色与场景稳定编号，沿用已有命名和造型；未提供的母版记为待制作。

## 拆镜规则

1. 按输入文本的剧情顺序拆镜，不提前展示后续信息，不增加无依据的重要剧情。口播稿已有倒叙时遵循稿件叙述，明确时间转换。
2. 每镜有明确叙事目的：观众第一眼看什么、主体正在做什么、环境如何表达这一刻。避免重复构图、空泛形容词和无剧情目的的摆姿。
3. 重要人物镜头写清“初始状态 → 事件触发 → 眼神/表情反应 → 身体动作 → 收势”。低动作幅度也要有重心、视线或呼吸变化，不靠夸张张嘴表现所有情绪。
4. 维持相邻镜头的左右位置、视线、运动方向、伤势、武器及服装状态。改变轴线或空间时设计交代镜头；已确定的角色母版不得逐镜重设计。
5. 明确前、中、后景及远景的可见元素、尺度参照、遮挡关系和主体占比。宇宙场景避免无意义碎石、密集漂浮物和过量光效。
6. 指定机位、景别、焦点及运镜时间变化。10 秒镜头可用 0–2 秒建立、2–7 秒核心动作、7–10 秒收势，其他时长相应调整；阶段须完整覆盖该镜时长。
7. 灯光注明来源与方向、环境光和必要的轮廓光；特效光应合理照到人物。避免无来源发光、全场均匀补光和特效遮脸。
8. 战斗写清判断、蓄力、出手、接触、反馈和收势。特效随动作触发，环境随力量响应；保持重量、惯性与受力，不把战斗写成站桩互放光波。
9. 每镜动作数量适合实际视频工具与时长。复杂交战、多角色或多次运镜难以一次生成时拆镜，并标记制作难点。声音注明对白、旁白、音效及 BGM 氛围，不假定已获得音频素材。

## 输出表

长篇可按幕输出，保持镜号连续。明确时长单位；有目标总时长时校准所有镜头之和，不把未完成部分计入已完成镜数。

表后列出总镜数、预计总时长、人物表演重点、环境展示重点、灯光重点、最难制作镜头、生成稳定性风险，以及需要提前完成的角色/场景/道具母版。

## 三轮自检

输出前完成并修复：

1. 剧情与人物：事件顺序、原文依据、角色动机、站位和动作因果。
2. 镜头与空间：衔接、轴线、尺度、运镜、单镜阶段覆盖和总时长计算。
3. 制作可行性：人物表演、光源、特效量、母版一致性和复杂动作的可生成性。

默认输出修正后的分镜及制作摘要；仅在用户要求时展示审查记录。
