# 参考视频拆解学习

先读 [制作默认值](../../references/production-defaults.md)。区分用户要学习方法、复用格式，还是生成新作品；依本次要求交付。

## 读取证据
1. 有视频文件或链接时先用 [video](../video/SKILL.md) 读取；本地文件也可用 [抽帧脚本](scripts/extract-frames.sh)。需要 Bash、FFmpeg、ffprobe 和 awk；转写另需可用语音后端或用户提供的台词。
2. 先取得完整时长、带时间戳的转写和关键帧。均匀抽帧仅供概览；开场、转折、切点和高速动作需补取对应时间的帧，不能用少量静帧推断整段运动。
3. 只有文案时明确只做文案拆解，画面、音效、剪辑和时间戳不作事实判断。缺口标为待核实，不把推测当观察。
4. 不需要 Novoads 账号或付费分析即可做本地拆解。任何外部上传、付费或生成仅在用户明确授权对应动作后进行。

## 分析
- 先解释观众为什么继续看：具体异常、信息缺口、危机、好奇或情绪，而非只贴“黄金三秒”等标签。
- 按事件/剪辑边界分段；提取每段目的、信息推进、句式、画面配合和转场。引用时间戳支撑视频观察。
- 区分可跨作品复用的结构、只能沿用本案例的内容、依赖素材/表演/剪辑才成立的效果。
- 优秀样稿已有流量反馈时以学习为目标；不根据抽象结构否定样稿，也不保证复用后获得同样流量。
- 找出最值得练的 2～3 项，给出练习动作及可观察的验收标准。
- 复用使用变量、结构和方法，不把原样复制整篇当作学习成果。不机械压成 15 秒广告模板。

## 输出
1. 一句话解释核心吸引力。
2. 分段表：时间/原文片段、作用、可复用方法、适用条件。
3. 最多 3 项重点学习动作及验收。
4. 用户需要 SOP 时提供可执行流程；只有用户要求新稿、生成提示词或新视频时进入下一阶段。

[上游广告模板原文](UPSTREAM.md) 仅在用户明确需要 Seedance/Novoads 广告公式时查阅；其模型限制、英文语速和 API 流程不适用于普通国漫解说。
