# 参考图局部编辑

先读 [制作默认值](../../references/production-defaults.md)，用户当前要求覆盖默认值。

## 输入与工具边界

取得本次要编辑的原图，先实际查看，再确认具体修改对象、区域和目标。多张图时区分场景母版、角色参考及风格参考，不自行混用。缺少原图或修改目标时先索取。

用户只要提示词时输出编辑指令；用户要求修图且有可用编辑工具时执行并检查结果。根据可用工具选择局部编辑、蒙版或确定性变换；没有图像编辑能力时明确说明，只交付可执行指令，不能声称图片已修改。

## 保留项

除用户明确允许修改的属性外，以当前原图为基准保持：

- 主体身份、数量、轮廓、比例、五官、发型、服装、武器、材质和纹路。
- 场景结构、背景物件、主体位置、朝向、尺度及遮挡关系。
- 机位、景别、透视、构图、画幅和空间纵深。
- 主光方向、环境光、明暗关系和整体色彩。

保留项服从本次明确要求。例如改变朝向会影响可见轮廓，移动主体会改变遮挡和接触阴影；把这些必要变化列为连带修改，不承诺所有像素不变。目标与保留项无法兼容时，说明冲突并取得用户选择后再执行。

## 编辑流程

1. 写清“唯一允许修改的内容”，将对象、区域、目标状态和必要连带变化限定到可观察范围。尽量用原图中位置、外观或用户蒙版指认对象。
2. 有蒙版能力时只覆盖目标及必要边缘过渡区。移动、替换或移除物件时，仅修补原位置、边缘、遮挡和接触光影所需区域。
3. 指令强调在原图上编辑、保留主体身份及其余区域。禁止把局部修图执行为整体重新设计。用户指定的画幅和透明背景应保持。
4. 生成后实际查看结果并对照原图，检查允许区域、主体身份、数量、结构、透视、构图和光影。精确像素保留的要求应使用可验证的蒙版或合成方案；生成式编辑不能保证像素完全一致。
5. 如出现明显身份漂移或非目标区域改动，收窄区域和指令，最多追加两次修正。仍不合格时交付真实状态和具体差异，不把失败结果称为验收通过。

## 指令结构

按当前任务填写以下四项，不保留空占位：

- 基准：哪张图是唯一场景母版，其他参考图只提供什么信息。
- 允许修改：对象、位置、目标及必要连带变化。
- 必须保留：与本次修改无关的主体、场景、镜头和光影属性。
- 验收：目标是否实现、是否新增或丢失元素、是否改变身份、是否影响非目标区域。

## 交付

执行编辑后提供最终图片或可访问的文件链接，并简述实际修改；有残留差异必须说明。只编写提示词时输出完整指令，避免声称已执行。此技能不自动发布图片或上传到外部项目。
