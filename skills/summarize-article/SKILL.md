# 总结文章要点

## 步骤

1. 阅读用户提供的文章内容
2. 提取核心观点和关键信息
3. 按重要性排序，输出结构化要点
4. 如果文章较长，先分段落总结，再整合

## 输出格式

```markdown
## 文章要点

- **核心观点**：一句话概括
- **关键要点**：
  - 要点 1
  - 要点 2
  - 要点 3
- **结论 / 建议**（如有）
```

## 注意事项

- 保持客观，不要添加文章里没有的内容
- 要点尽量简洁、具体
- 如果用户提供了链接，先读取内容再总结
