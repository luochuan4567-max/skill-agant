# 制作默认值

用户本次明确要求、当前母版及项目设定优先于本页。以下是无冲突时的默认值，不机械套用到所有题材。

## 小说解说
- 一集围绕唯一主线，按事件因果推进危机、应对、代价和转折；设定依附正在发生的事件。
- 保留原著重要对白、人物逻辑和真实结果；不虚构战斗、放水、阴谋或提前透支后续剧情。
- 中文配音估算采用每分钟 290～310 个有效文字（不计标点和空白）；实际以录音为准。
- 字幕按自然语义切屏，每屏尽量不超过 28 字；不要为了短句切断主语或因果。
- 优先最小范围修改。平台节奏是参考，不能为凑字数制造反转。
- 结尾根据素材留下未解决危机或自然收束；素材没有悬念时不编造。

## 图像与视频
- 默认真实 3D CG / PBR；避免 2D 平涂、玩具感和过量炫光。
- 默认单张完整画面；只有用户明确要求宫格、多视图或分组预演时采用对应布局。
- 场景资产默认纯场景；人物/武器建模默认白底。人物设定图可备注姓名；其他画面默认无字，海报按要求加字且脸部清楚。
- 以用户当前指定图为唯一母版。局部修改保留未授权改变的主体、构图、材质、视角和光影。
- 星空保持干净深空与星系结构，默认不添加碎石、陨石、黑色漂浮岩块。黑雾用真实流体表现。
- 10 秒镜头默认 0～2 秒建立、2～8 秒核心动作、8～10 秒收势，对应第 1～2／3～8／9～10 秒。
- 单镜以一项核心动作展开，必要的准备、接触、反馈和收势服务该动作；复杂交战需拆镜。
- 保持人物、武器、伤势、服装、站位和运动方向连续，避免身份漂移与多元素融合。
